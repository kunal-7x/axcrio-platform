- **`<audio src>` / `<img src>` CANNOT send Authorization/X-Auth headers** → the browser fetches naked → 401 → JS `.catch` swallows it → "no preview". → Add a `?t=<jwt>` query-param fallback auth scoped to that public-sample route (validate `t` via a `_FakeReq` Bearer adapter through the same resolve_tenant path); render `<audio>` ONLY when `playable===true && presigned_url`. The private-Spaces-URL → 403 blank bug RECURS (images, recordings, video) — always serve a PRESIGNED GET url + HEAD-verify the object is non-empty before presigning (a 486-busy OGG decodes to silence).
- **API-key/secret plaintext in React `useState` leaks into devtools/state.** → Keep plaintext in a `useRef` only; wipe on unmount/timeout/Hide; copy-without-revealing from the ref; input type=password never prefilled; the FE never receives a raw key, only masked.
- **A pure presentational re-housing must NOT migrate state or change APIs.** → Keep ONE component owning all state, add only `useState(step)`, move pieces inside `{step===N && …}`, gate forward nav on per-step validity, keep completed steps clickable-back.
- **Dormant/flag-off routes return 404** → render a calm empty/coming-soon state (treat 404 as not_configured), NEVER an error wall or a logout.
- **Inbound calls write no CRM timeline row** (`contact_timeline` has 0 inbound rows; aim_voice_agent never writes one) → the CRM never surfaces an inbound call to click. → Inbound calls must write a timeline/session row for the UI to show the transcript.
- **Build/tsc gotchas:** a `tsc TS1127 "Invalid character"` storm in a file you never edited = a prior session pasted TUI box-drawing chars → `git checkout HEAD -- <file>`, don't hand-repair. A Next.js TS2344 `params` route-type error → extract the body to `_body.tsx`, leave `page.tsx` a thin propless wrapper. A wrapper-hook chained optional access (`q.data?.calls?.length`) can narrow `q.data` to `never` → explicit `useQuery<T,Error,T>` generics + compute the array once. On Windows `npm run build` exits 1 with `kill EPERM` AFTER "Compiled successfully" (Next worker-teardown quirk, build IS complete; doesn't happen on Linux). Code-split (`next/dynamic ssr:false`) ONLY heavy deps on a LIVE route with a clean default-export wrap point (@xyflow, Aurora); keep re-exported TYPES static.
- **A native Basic-auth popup always means a real `WWW-Authenticate: Basic` on a 401 somewhere.** "Can't find it" = you probed the wrong METHOD (HEAD→405 hides the header) or PATH (app route vs the `/api/*` the SPA fetches). → `curl -s -D - -o /dev/null -X GET` each /api route; here it was `caller.py need_auth()` — drop the header, keep 401.

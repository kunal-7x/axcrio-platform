**Purpose.** This folder is the durable institutional memory of the autonomous-build
system. Every deep research/workflow run is preserved here UNCOMPRESSED so any future
session or agent can load crazy-level context on demand instead of starting cold. The
operating prompt (`C:\Users\kunal\Desktop\caps\MAX_AUTONOMY_PROMPT.md`) is the *compressed* form;
THIS archive is the *full* form. When a future agent needs depth, read this index first,
then pull the specific file it points to.

**How to use (future agent / new session):**
1. Read this index to see what research exists.
2. For full fidelity, read the matching `raw/NN-*.raw.json` (the complete workflow output).
3. For the per-agent unsummarized research, open the listed **transcript dir** (durable,
   under `.claude/projects/.../subagents/workflows/<runId>/`).
4. For the distilled operating-form, see the named **Prompt Parts** in MAX_AUTONOMY_PROMPT.md.

**Layout:**
- `RESEARCH_INDEX.md` — this file (what each entry holds).
- `raw/NN-*.raw.json` — full uncompressed *synthesized* workflow output (JSON with two markdown fields).
- `agents/NN-*.agents.md` — the **raw per-agent research** (every individual agent's full prompt + full
  unsynthesized output). This is the LEAST-compressed, highest-detail source — the archive is now 100%
  self-contained (no dependency on transcript folders). Open these when you want maximum depth on a topic.
